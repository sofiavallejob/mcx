# mcx

Multichannel tools for Pure Data vanilla (0.54+). Small C externals that fill
the gaps people keep asking about on the Pd forum and GitHub.

| Object | What it does |
| --- | --- |
| `mcx/mcexpr~` | A signal expression evaluated once per channel. Knows the channel index (`ch`) and channel count (`nch`), takes one value per channel from lists. |
| `mcx/mcsum~` | Mix all channels down to one, with optional per-channel weights. |
| `mcx/mcnchs~` | Channel count of a multichannel connection, reported automatically when it changes. |
| `mcx/mcprint~` | See inside a multichannel cable: first sample, peak or full block per channel. |

## Examples

```
[mcx/mcexpr~ -n 8 220 * (1 + ch * 0.004)]   8 detuned frequencies
|
[osc~]
|
[mcx/mcsum~]
```

```
[200 250 300 375(        a list sets one value per channel
|
[mcx/mcexpr~ -n 4 f1]
```

Open the help files for the full reference.

## Install

In Pd: Help > Find externals, search `mcx`.

## Build

Needs the Pd source (for the headers) and pd-lib-builder (included):

```
git clone --depth 1 https://github.com/pure-data/pure-data.git pd
make PDINCLUDEDIR=pd/src
```

Every push builds Linux, macOS and Windows binaries on GitHub Actions and
makes a ready deken package (Actions tab, artifact `mcx-deken`).

The help files are generated by `tools/build_help.py`.
